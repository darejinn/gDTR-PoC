# `figures/` — figure asset catalog (v4 positional naming)

Every PNG / PDF / TikZ source under this directory matches its position
in the rendered PDF: main-text figures are `fig_<N>_*` (N = 1, 2, 3) and
appendix figures are `fig_A<N>_*` (N = 1, 2, 3, 4 — matching the
A-prefixed numbering enabled in `gdtr_paper_ICML.tex` after `\appendix`).

For the figure → script → upstream-data mapping, see
[`../MANIFEST.md`](../MANIFEST.md).

## Edit policy

- The `fig_<N>_*` and `fig_A<N>_*` naming convention is canonical: the
  prefix matches the position in the PDF. If you renumber, rename the
  files in lockstep with the LaTeX `\includegraphics` paths.
- Raster figures (`*.png` / `*.pdf`) should be regenerated from the
  scripts under `../scripts/` rather than edited in place; replacing
  PNGs by hand will desync the captioned numbers from the result
  artifacts.
- Figure title fonts are **Times New Roman** (set via
  `fontfamily="Times New Roman"` in each `set_title(...)` /
  `suptitle(...)` call). Body text remains DejaVu Sans, matching the
  LaTeX `\sffamily` for figure-text consistency in the PDF.
- Fig A4 is the one figure whose title font we don't control (external
  render). Document the inconsistency in `MANIFEST.md` if needed.
